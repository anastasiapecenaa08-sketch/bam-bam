# Parker 🐾

Сайт-презентация про Паркера — тибетского мастифа. Тёмный фон, у каждого
слайда свой акцентный цвет и своё фото. Текст на сайте на английском.

## Как открыть

Откройте `index.html` в браузере — сборка и установка не нужны.

## Управление

- колесо мыши / трекпад — следующий или предыдущий слайд
- стрелки ↑ ↓ ← →, PageUp / PageDown, пробел, Home / End
- свайп вверх / вниз на телефоне
- точки справа — переход к любому слайду
- у каждого слайда есть свой адрес: `index.html#sleep`, `#food`, `#bark` и т.д.

## Как поменять

- Текст — в `index.html`.
- Фото — замените файл в `photos/` на другой с тем же именем.
- Цвет слайда — атрибут `style="--accent: ...; --accent-2: ..."` у нужной
  секции в `index.html`.
