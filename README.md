# Бам-Бам 🐾

Сайт про пса Бам-Бама в тёмных цветах с яркими акцентами.

## Как открыть

Откройте `index.html` в браузере — сборка и установка не нужны.

## Как добавить свои фото

Положите фотографии в папку `photos/`:

| Файл              | Где показывается        |
| ----------------- | ----------------------- |
| `photos/hero.jpg` | большое фото наверху    |
| `photos/1.jpg` … `photos/6.jpg` | галерея   |

Пока фото нет, на их месте будут цветные заглушки с эмодзи.

## Как поменять текст и цвета

- Текст (возраст, порода, характер, распорядок) — в `index.html`.
- Цвета — в начале `styles.css`, в блоке `:root`
  (`--orange`, `--mint`, `--pink`, `--violet` — акцентные цвета).
